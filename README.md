# For My Cutie Yogu Babu ♡

A personalised, responsive apology website for Yogyata (Malkin Ji), including a memories gallery for two photos and one short video.

## Add your two photos and 6-second video

1. Choose two photos and one short video (about 6 seconds).
2. For best results, use JPG/JPEG photos and an MP4 video (H.264 video + AAC audio).
3. In the website folder, create a folder named exactly `memories`.
4. Put your files inside it and rename them exactly:
   - `photo-1.jpg`
   - `photo-2.jpg`
   - `our-moment.mp4`
5. The website already looks for those exact filenames. Keep the spelling and lowercase letters the same.
6. If your photos are PNG or WEBP, either convert them to JPG or change the matching image filename in `index.html`. If your video is MOV, convert it to MP4 for best browser compatibility.
7. Re-upload/commit `index.html` and the complete `memories` folder to your GitHub repository. The gallery will then show the photos and video.

## Publish free with GitHub Pages

1. Sign in to https://github.com/ and create a new **public** repository (for example, `for-yogyata`).
2. Upload `index.html`, `README.md`, and the `memories` folder with the three media files into the repository root (top-level).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then press **Save**.
6. Wait a minute or two. GitHub will show your live website URL on the Pages settings screen.

No paid domain or hosting is needed. The site is static HTML/CSS/JavaScript and works on mobile.

## Important privacy and file-size notes

- A public GitHub Pages site is accessible to anyone who has the URL; it is not password-protected. Avoid uploading anything either person would not want shared.
- Keep the video short and compressed. GitHub has repository file-size limits; a small MP4 (ideally under 10–20 MB) is a good target.
- The website does not provide a public visitor upload form. You add the media to the repository yourself, so the same memories appear for everyone visiting the page.
- If you later change a caption, edit it in `index.html` and commit the update.

## Personalising it further

Search in `index.html` for the memory captions and replace them with your own specific memory details. The Google Fonts import needs an internet connection; system fonts remain as fallback if it is unavailable.

## A thoughtful note

Only keep promises you genuinely intend to follow through on. The page is meant to express care, not pressure someone to forgive or respond.
